知识目录 · 展开层级记忆

点箭头展开 / 收起；「重新打开网页」只恢复上次展开的路径

目录树与新增目录规则

  1. 修复「目录不展开 / 点击没反应」：首屏从本地记忆恢复空间时显式加载该空间目录树；展开箭头改为可点击、可键盘操作的容器。
  2. 不再默认全展开：无缓存只显示 L1；展开 / 收起按空间写入 inuwiki.categoryExpanded，返回主页仅恢复上次打开的层级，其他自动收起。
  3. 逐级展开：所属目录下拉与新增目录弹层都默认只显示 L1；点目录行或箭头才展开下级，可逐层下钻；带入默认父级时只展开它的祖先链路。
  4. 目录最多 L5：L5 不能作为父级（弹层禁用并标注「已达上限」），前端提交拦截，后端创建 / 改父级均做深度校验。
  5. 名称最多 15 字：示例文案「如：会议纪要」，输入框 maxlength=15 + 实时计数；后端创建与重命名都按字符数（mb_strlen）校验。
  6. 「未指定目录」默认存在：每个空间自动补齐、永远置底；未指定文章归入其中，删除目录时子目录与文章移入其中；不可改名 / 移动 / 删除。

设计说明（一致性 / 层级 / 反馈 / 无障碍）

  • 一致性：新控件全部复用现有令牌（--r-* 圆角、--sh-* 阴影、--line 描边、焦点环），与空间下拉同一套语言。
  • 层级可读：选中值显示完整面包屑；每项带 L1 ~ L5 徽标，层级不只靠缩进和颜色表达。
  • 渐进展开：所属目录下拉与新增目录弹层都默认只显示 L1；点目录行或箭头才展开下级；所属下拉搜索时自动展开命中项的祖先链。
  • 先选层级再命名：弹层用单选树选父目录（含「作为一级目录」），实时预览「空间 / 父链 / 新目录」与「第几级 / 最多 L5 级」，L5 目录禁止再作父级。
  • 即时反馈：同级同名即时拦截并说明原因、15 字计数与超限提示、创建中禁用提交；创建成功后刷新目录树并自动选中新目录。
  • 无障碍：原生 button + role="radiogroup/radio" + aria-checked/expanded/selected、label 关联、Esc 关闭、键盘可选。
  • 层叠：弹层 Teleport 到 body，避开 .rise transform 生成的层叠上下文（此前空间下拉被遮挡就是该原因）。
参数：?dialog=0 关闭弹层看设置页全貌；?picker=1 展开所属目录下拉；?fresh=1 演示全新文章（下拉仅 L1）；?limit=1 演示第 5 级与 L5 已达上限。上方「知识目录 · 展开层级记忆」可点箭头、清除缓存、模拟重新打开网页。真实页面按 kb:category:manage 权限显示按钮。
根因修复（本轮）： 门户列表页把「加载分类树」只放在 watch(spaceId) 里， 而空间 ID 是从本地记忆恢复的、首屏不会触发 watch，于是重新打开网页 / 从新增文章返回主页时 侧栏拿到的是空目录，看起来「没展开、点了也没反应」。现已在 onMounted 显式加载该空间的目录树， 并把展开箭头改成可点击、可键盘操作的容器；展开状态统一由 KbNavTree 持有并写入 inuwiki.categoryExpanded（按空间隔离），收起父目录时连带收起后代。
